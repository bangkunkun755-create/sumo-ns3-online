## 数据及发布保护

- 原 Python 顶层文件、原 C++ 和路网仅复制；便携性修改只发生在发布副本。
- 未把原历史 runs、.idea、__pycache__、本机 .local 路径、完整 ns-3 或编译产物放入发布包。
- 路网快照受记录的哈希约束；缺失或内容被改会拒绝验收。快照相对路径不得越出结果目录。
- 安装脚本不下载依赖、不运行 sudo、不静默覆盖不同内容的场景；显式替换时先保留备份。
- 压缩工具采用文件白名单，生成 `MANIFEST.sha256` 并检查 ZIP CRC 和每个成员的内容。
- 第三方许可副本予以保留；本次没有代替负责人选定原创部分的开源许可证，公开前仍须确认。

## 已知边界

实验为单车、固定种子、802.11g ad-hoc 和每秒的应用层最近目标选择。未加入蜂窝/L2切换协议、滞回、鉴权、回传链路或网络反馈控制交通。默认参考结果只适用于给定版本、参数和模型，不能外推为多车或毫米波性能保证。
